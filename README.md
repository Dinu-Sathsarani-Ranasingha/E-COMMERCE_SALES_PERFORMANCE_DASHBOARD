# 📊 E-Commerce Sales Performance Dashboard

An end-to-end **Data Analytics Project** built using **SQL, Python, and Power BI** to analyze sales performance, calculate business KPIs, develop an interactive dashboard, and generate actionable business insights.

---

# 📌 Project Overview

This project analyzes an E-Commerce Superstore dataset to identify sales trends, customer behavior, regional performance, and product profitability. The project follows a complete analytics workflow from raw data to business recommendations.

---

# 🎯 Project Objectives

* Clean and prepare the dataset
* Perform business analysis using SQL
* Calculate KPIs using Python
* Build an interactive Power BI dashboard
* Generate business insights and recommendations

---

# 🛠️ Tools & Technologies

* Python (Pandas, Matplotlib)
* SQL
* Power BI Desktop
* DAX
* Jupyter Notebook

---

# 📂 Project Workflow

## ✅ Phase 1 – Exploratory Data Analysis (EDA)

* Data Cleaning
* Missing Value Analysis
* Duplicate Removal
* Data Type Validation
* Exploratory Data Analysis

---

## ✅ Phase 2 – SQL Business Analysis

Business questions answered using SQL:

* Top Customers
* Sales by Category
* Sales by Region
* Monthly Sales Trend
* Top Products
* Loss-Making Products
* Product Performance Analysis

---

## ✅ Phase 3 – KPI Analysis (Python)

Calculated KPIs:

* Total Revenue
* Total Profit
* Profit Margin
* Average Order Value (AOV)
* Average Discount

Additional Analysis:

* Sales by Region
* Sales by Category
* Profit by Customer Segment
* Product Performance

---

## ✅ Phase 4 – Power BI Dashboard

Interactive dashboard includes:

* KPI Cards
* Monthly Revenue Trend
* Sales by Region
* Sales by Category
* Profit by Segment
* Top Revenue Products
* Loss-Making Products
* Interactive Slicers (Year, Region, Category)

---

## ✅ Phase 5 – Business Insights & Storytelling

The dashboard findings were converted into business insights and strategic recommendations.

### Executive Summary

A business report was prepared to explain the dashboard results from a business perspective.

### Key Business Insights

* Technology generated the highest revenue.
* Consumer customers contributed the highest overall profit.
* The West region recorded the highest sales.
* Some high-revenue products generated negative profit.
* Profit margin indicates opportunities for profitability improvement.

### Business Recommendations

* Increase investment in Technology products.
* Expand successful sales strategies from the West region.
* Review pricing and discounts for loss-making products.
* Improve profitability through discount optimization.
* Strengthen customer retention programs.
